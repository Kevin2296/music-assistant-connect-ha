STAP 1

Verbind Music Assistant

Home Assistant Ingress

Eén tik is genoeg: Music Assistant maakt met jouw Home Assistant-login een eigen toegangssleutel voor deze app. Je hoeft niets te kopiëren. De sleutel blijft op je HA-server.

Handmatig verbinden

Maak in Music Assistant een token via Instellingen → Profiel. Stel server en token vooraf in via Home Assistant → Instellingen → Apps → Music Assistant Connect → Configuratie. Het ingestelde token blijft op de server; handmatige invoer blijft alleen in het geheugen van deze pagina.

Via DuckDNS: open deze app vanuit je bestaande HTTPS Home Assistant-toegang. Het interne MA-adres blijft hetzelfde.

STAP 3

Verbinding instellen

Eenmalige privébrowser

Bedien deze gewone browser op je HA-server: klik, typ of sleep zelf. De ingebouwde cookie-extensie haalt alleen na jouw klik op ophalen gegevens uit deze tijdelijke sessie. Je hoeft geen extensie op je telefoon te installeren.

Open Home Assistant via HTTPS (ook via DuckDNS) of een beveiligde VPN. Je gewone telefoonbrowser deelt zijn cookies niet met deze sessie. Google of SoundCloud kan ook deze browser weigeren; een succesvolle aanmelding is niet gegarandeerd.
Tijdelijke browser
Browser starten…

Staan de cookieknoppen buiten beeld? Kies Omlaag scrollen en maak zelf je cookiekeuze. Je kunt ook het muiswiel gebruiken. Sleep een schuifje zelf binnen het beeld. Deze app lost geen CAPTCHA voor je op. Het beeld wordt automatisch bijgewerkt.

Wacht met ophalen tot je volledig bent ingelogd en een persoonlijke afspeellijst hebt geopend. De browser sluit zodra alle benodigde gegevens gevonden zijn. Werkt inloggen niet? Plak de gegevens handmatig volgens de providerhandleiding. Cookies kunnen verlopen; opnieuw koppelen blijft dan nodig.

Privacy eerst

Zelfgehost, geen analytics, geen cloudaccount voor deze app. Gevoelige gegevens blijven op je eigen Home Assistant-server. Gebruik je bestaande HTTPS Home Assistant-toegang, ook buitenshuis. Je hoeft geen extra poort open te zetten.
